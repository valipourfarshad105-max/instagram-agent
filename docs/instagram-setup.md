# راهنمای اتصال اینستاگرام به ایجنت (قدم‌به‌قدم)

این تنها بخشی است که باید یک‌بار خودتان انجام دهید (~۲۰ دقیقه). بعد از آن، ایجنت
خودش پست می‌سازد و منتشر می‌کند.

> ⚠️ نکتهٔ امنیتی مهم: هرگز رمز اینستاگرام را به هیچ برنامه‌ای (از جمله این ایجنت) ندهید.
> انتشار رسمی فقط با «توکن دسترسی» انجام می‌شود که خودتان از پنل متا می‌سازید و هر زمان
> می‌توانید باطلش کنید. ایجنت هرگز رمز شما را نمی‌بیند.

---

## ۰) پیش‌نیاز: نوع اکانت

انتشار خودکار فقط برای **اکانت حرفه‌ای (Business یا Creator)** فعال است. اکانت شخصی
نمی‌تواند از این API استفاده کند.

**چطور چک کنید:** در اپ اینستاگرام → پروفایل → منوی سه‌خط (بالا راست) → **Settings and
activity** → دنبال گزینهٔ **Account type and tools** یا **Switch to professional
account** بگردید:

- اگر این گزینه را می‌بینید ⇒ اکانت شما **شخصی** است و باید تبدیلش کنید.
- اگر زیرش نوشته **Business** یا **Creator** ⇒ اکانت شما حرفه‌ای است ✅

**تبدیل اکانت (۱ دقیقه):** همان مسیر → **Switch to professional account** → دستهٔ
مناسب (مثلاً Business) → ادامه. اطلاعات شما و فالوورها دست‌نخورده می‌ماند.
(اگر بعداً خواستید، می‌توانید برگردید؛ ولی برای انتشار خودکار لازم است.)
Creator هم قبول است، ولی Business مطمئن‌ترین گزینه برای انتشار از طریق API است.

## مسیر ۱ (پیشنهادی): Instagram API with Instagram Login

این مسیر **بدون نیاز به پیج فیسبوک** کار می‌کند و ساده‌تر است. Enter (نوع اکانت شما
نامعلوم بود، این مسیر بهترین شروع است.)

### ۱-۱) ساخت اپ متا
1. برو به <https://developers.facebook.com/apps> و با حساب فیسبوک وارد شو
   (حساب فیسبوک لازم است، ولی پیج لازم نیست — یک حساب شخصی کافی است).
2. **Create app** → نوع **Business** را انتخاب کن → نام دلخواه (مثلاً `my-instagram-agent`)
   → همان اپی که ساخته می‌شود را باز کن.

### ۱-۲) افزودن محصول Instagram
1. در داشبورد اپ → **Add product** → کنار **Instagram** روی **Set up** بزن.
2. از منوی چپ → **API setup with Instagram login** (یا «Instagram > API setup»).
3. در بخش **Generate access tokens**: دکمهٔ **Add account** / **Connect account** را بزن و
   اکانت اینستاگرام خودت را وصل کن (وارد شدن با اینستاگرام).
4. دسترسی‌های زیر را تیک بزن:
   - `instagram_business_basic` (اجباری)
   - `instagram_business_content_publish` (**انتشار پست؛ اجباری**)
5. توکن تولیدشده را کپی کن. **این توکن بلندمدت (۶۰ روزه) است.**
   تا زمانی که اپ شما در حالت توسعه (Development) است، این توکن برای انتشار در
   پیج خودتان کافی است و **نیازی به App Review ندارید** (چون شما ادمین همان اپ و
   همان اکانت هستید).

### ۱-۳) پیدا کردن Instagram User ID
با توکنی که دارید:

```bash
curl -s "https://graph.instagram.com/v23.0/me?fields=id,username,account_type&access_token=TOKEN_شما"
```

خروجی نمونه:
```json
{"id":"17841400000000000","username":"my.page","account_type":"BUSINESS"}
```

آن `id` (عدد اول) همان **IG_USER_ID** است.

### ۱-۴) گذاشتن در فایل `.env`
```env
IG_LOGIN=instagram
IG_ACCESS_TOKEN=توکنی که کپی کردید
IG_USER_ID=17841400000000000
```

### ۱-۵) تست
```bash
python -m agent.cli ig-check
python -m agent.cli publish-limit     # سهمیهٔ ۲۴ ساعت گذشته
```
اگر نام و آی‌دی اکانت چاپ شد، اتصال کامل است ✅

## مسیر ۲: Instagram API with Facebook Login (نیازمند پیج فیسبوک)

اگر پیج فیسبوک دارید و اکانت اینستاگرامتان به آن وصل است، این مسیر هم در دسترس است.

1. مثل بالا یک اپ **Business** بساز، محصول **Instagram** را اضافه کن و این بار
   **API setup with Facebook login** را انتخاب کن.
2. پیج فیسبوک را وصل کن و دسترسی‌ها را بگیر:
   `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `business_management`
3. `IG_USER_ID` در این مسیر، **شناسهٔ اکانت اینستاگرامِ وصل‌شده به پیج** است، نه شناسهٔ پیج:
   ```bash
   # فهرست پیج‌ها و اکانت اینستاگرام متصل به هرکدام
   curl -s "https://graph.facebook.com/v23.0/me/accounts?fields=name,instagram_business_account&access_token=TOKEN"
   ```
4. مقادیر را در `.env` بگذارید:
   ```env
   IG_LOGIN=facebook
   IG_ACCESS_TOKEN=...
   IG_USER_ID=...            # همان instagram_business_account.id
   FB_APP_ID=...
   FB_APP_SECRET=...
   ```
5. توکن Facebook را به توکن بلندمدت تبدیل کنید (Graph API Explorer → دکمهٔ
   «Extend Access Token») و نتیجه را در `IG_ACCESS_TOKEN` بگذارید.

## نگه‌داری توکن (مهم)

- توکن اینستاگرام حدوداً **۶۰ روز** اعتبار دارد. ایجنت هر ۳۰ روز یک‌بار خودش تلاش می‌کند
  تمدید کند (`refresh-token`) و توکن جدید را در لاگ/تلگرام نشان می‌دهد؛ ولی **جای‌گذاری
  مقدار جدید در `.env` با شماست** (خودکار انجام نمی‌شود تا رمز/توکن شما دست‌نخورده بماند).
- راه دستی:
  ```bash
  python -m agent.cli refresh-token
  ```
- اگر خطای `Session has expired` یا `Invalid OAuth access token` دیدید، یعنی توکن تمام شده
  و باید از مرحلهٔ ۱-۲ توکن جدید بسازید.

## محدودیت‌ها و مشخصات فنی ریلز (که ایجنت رعایت می‌کند)

| مورد | مقدار | وضعیت در ایجنت |
|---|---|---|
| نسبت تصویر | ۹:۱۶ | ✅ ۱۰۸۰×۱۹۲۰ |
| طول ویدیو (تاب ریلز) | ۵ تا ۹۰ ثانیه | ✅ پیش‌فرض سقف ۹۰ ثانیه |
| کدک | H.264، پروفایل پیشرونده | ✅ libx264 |
| صدا | AAC، حداکثر ۴۸ کیلوهرتز | ✅ AAC 44.1kHz |
| نرخ فریم | ۲۳ تا ۶۰ | ✅ ۳۰ fps |
| جابه‌جایی moov | ابتدای فایل | ✅ `+faststart` |
| حجم فایل | تا ۱۰۰ مگابایت (تا ۴ گیگ در منابع جدید) | ✅ معمولاً ۳ تا ۸ مگابایت |
| کپشن | حداکثر ۲۲۰۰ کاراکتر، ۳۰ هشتگ | ✅ با اعتبارسنجی |
| سقف انتشار | حدود ۲۵ پست در ۲۴ ساعت (در نسخه‌های جدیدتر بیشتر) | ✅ با `max_posts_per_day` کنترل می‌شود |

برای دیدن سهمیهٔ واقعی اکانت خودتان: `python -m agent.cli publish-limit`

## عیب‌یابی خطاهای رایج

| خطا | معنا | راه‌حل |
|---|---|---|
| `The user is not an Instagram Business` | اکانت حرفه‌ای نیست | بخش ۰ این سند |
| `Invalid OAuth access token` | توکن منقضی/غلط | توکن جدید بسازید |
| `(#10) Application does not have permission` | دسترسی publish داده نشده | `instagram_business_content_publish` را در پنل اضافه کنید |
| `9004: The media could not be fetched` | اینستاگرام نتوانست ویدیو را از URL دانلود کند | آپلودر را عوض کنید (S3/R2 بگذارید) یا لینک را در مرورگر تست کنید |
| `2207003: It takes too long to download` | سرعت هاست پایین است | از میزبان سریع‌تر (R2/S3) استفاده کنید |
| `Aspect ratio not supported` | نسبت تصویر اشتباه | تنظیمات `video.width/height` را ۱۰۸۰×۱۹۲۰ بگذارید |
| `Media container not finished` | پردازش ویدیو طول کشید | ایجنت تا ۱۰ دقیقه صبر می‌کند؛ ویدیوی کوتاه‌تر بسازید |
| `(#4) Application request limit reached` | محدودیت نرخ API | چند ساعت صبر کنید یا سقف روزانه را کم کنید |
